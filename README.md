# Crimson Vigil

Create a simple dark superhero-themed website inspired by Marvel. Use a black background with red accents, bold white text, and a clean modern layout.

Include a navbar, a hero section with a large superhero image, a short tagline and button, plus a section with 4–6 superhero cards showing their names and powers. Add basic hover effects and make it responsive.

Keep the design simple, clean, cinematic, and easy to build.
